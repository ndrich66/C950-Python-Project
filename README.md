# C950-Python-Project
Delivery Route Optimization System

A Python application that calculates the most efficient delivery routes to minimize total delivery time.

Problem: Drivers waste time and fuel when packages are delivered in an unoptimized order. This tool solves that by determining the best sequence for each delivery run.

What it does: Takes a set of package destinations as input, applies routing algorithms to determine the optimal delivery order, and outputs a prioritized delivery sequence for the driver.

Built with: Python, using a greedy algorithm for route optimization and scheduling logic.

How to run it: Clone the repo, run the main Python file, and input your delivery destinations to receive an optimized route.
